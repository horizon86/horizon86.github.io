set

set -...: 开启某选项

set +...: 关闭某选项

set -o [option]: 具体设置某选项/输出所有选项的值

set -e: 出错就终止

set -u: 遇到未定义变量也终止

set -o pipefail: 管道中有错也停止

set -x: 开启命令回显

set +x: 关闭命令回显

一般脚本设置：set -euo pipefail

5. 单引号中转义单引号

由于反斜杠在单引号里面变成了普通字符，所以如果单引号之中，还要使用单引号，不能使用转义，需要在外层的单引号前面加上一个美元符号（$），然后再对里层的单引号转义。

不过，更合理的方法是改在双引号之中使用单引号。
